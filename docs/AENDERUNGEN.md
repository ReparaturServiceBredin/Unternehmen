# Änderungen

Neue Versionen werden automatisch als EXE veröffentlicht, sobald sich die Versionsnummer in
`rsb/__init__.py` (`VERSION_NUMMER`) ändert. Der Abschnitt zur jeweiligen Version erscheint im Programm
als Hinweis beim Update.

## 0.4.0
- Neu: Programm als **RSB-Buchhaltung.exe** – keine Python-Installation mehr nötig
- Neu: **Automatische Updates** – neue Versionen werden beim Start installiert (vorher Backup), oder per Knopf unter Einstellungen → Programm & Updates
- Doppelklick auf die EXE, während das Programm schon läuft, öffnet einfach den Browser

## 0.3.0
- Reparaturaufträge als Tafel (offen / in Arbeit / erledigt) mit Ziehen & Ablegen
- Kostenvoranschläge (KV-Nummern, PDF, E-Mail), automatischer Rechnungsentwurf bei „erledigt“

## 0.2.0
- Anfragen aus dem Kontaktformular automatisch abholen, Spam erkennen, Interessenten anlegen

## 0.1.0
- Kunden, Leistungen mit Marge, Rechnungen als PDF mit GiroCode, E-Mail-Versand, Storno, Backup
